API Service

This domain is intended for API access, not direct browsing.

It validates heartbeat calls, serves the public list of active servers, and provides backend functionality for browser and launcher clients.

Service Role

Core endpoints

list.php

Returns the current JSON list of active servers.

heartbeat.php

Accepts heartbeat updates from dedicated servers.

Public List

Server discovery

Browser and launcher use the same server list endpoint.

Heartbeat

Server status

Dedicated servers periodically prove that they are alive and update player counts here.

Schema

Shared data model

`servers.sql` defines the registry fields that the browser, dashboard and backend all speak.
