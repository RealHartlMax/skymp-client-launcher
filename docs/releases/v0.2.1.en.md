# SkyMP Launcher v0.2.1

Settings now supports sign-in with an existing SkyMP Worlds website account. After browser confirmation, the launcher shows the name, account ID, email and Discord link status. Sign-out is available in the launcher; the session is saved through Windows Credential Manager. This sign-in does not remap Steam identity, server approvals or game characters.

Steam is checked automatically when settings first opens. The result remains available throughout the launcher session, including after closing and reopening settings. Changing the game folder triggers another check; manual refresh remains available.

A notice appears across launcher pages when a newer official version is published. GitHub releases and the release catalog are checked at startup, periodically during use and on returning to the launcher. Settings → Game includes a manual update check. Downloads open in the browser; nothing installs automatically.

Windows crash diagnostics now use direct Windows APIs instead of PowerShell/WMI child processes. Release tooling checks code signatures and limits ZIPs to user files. This build remains unsigned; specific Defender results are recorded in the included validation evidence. There is no universal antivirus or SmartScreen guarantee.

**Downloads:** Full contains the complete portable launcher package. Update contains the identical EXE with update instructions and licenses. Close the launcher and replace its existing EXE; settings and profiles in the Windows user profile are retained. Requires Windows x64 and Microsoft Edge WebView2 Runtime. Skyrim, game server and native client runtime are separate packages.

**For operators:** Account linking requires the matching API/Manage web files, supplied separately. Already distributed older launchers need an update to obtain the new notice UI; their existing version view still depends on a published, current web catalog.

**Validation:** Backend, PHP sign-in, version logic and DE/EN/RU UI checks are documented in the local evidence. Production account testing, SmartScreen and full gameplay validation remain separate.
