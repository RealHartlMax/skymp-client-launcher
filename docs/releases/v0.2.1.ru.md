# SkyMP Launcher v0.2.1

В настройках появился вход через существующий аккаунт сайта SkyMP Worlds. После подтверждения в браузере лаунчер показывает имя, ID аккаунта, email и статус привязки Discord. Выйти можно прямо в лаунчере; сеанс сохраняется через Диспетчер учётных данных Windows. Вход не перепривязывает личность Steam, допуски серверов или игровых персонажей.

Steam проверяется автоматически при первом открытии настроек. Результат сохраняется в течение сеанса лаунчера, в том числе после закрытия и повторного открытия настроек. При изменении папки игры проверка выполняется заново; ручное обновление остаётся доступным.

При выходе более новой официальной версии уведомление появляется на всех страницах лаунчера. Релизы GitHub и каталог проверяются при запуске, периодически во время работы и при возвращении в лаунчер. В Настройки → Игра доступна ручная проверка. Загрузка открывается в браузере; автоматической установки нет.

Диагностика сбоев Windows использует прямые Windows API вместо процессов PowerShell/WMI. Средства выпуска проверяют подписи и включают в ZIP только пользовательские файлы. Эта сборка остаётся неподписанной; результаты Defender указаны в приложенных проверках. Универсальной гарантии для антивирусов или SmartScreen нет.

**Загрузки:** Full содержит полный портативный пакет лаунчера. Update содержит ту же EXE с инструкцией обновления и лицензиями. Закройте лаунчер и замените прежнюю EXE; настройки и профили в профиле Windows сохраняются. Нужны Windows x64 и Microsoft Edge WebView2 Runtime. Skyrim, игровой сервер и нативный клиентский runtime поставляются отдельно.

**Для операторов:** Вход требует соответствующих файлов сайтов API/Manage, поставляемых отдельно. Уже распространённые старые лаунчеры получат новый интерфейс уведомлений после обновления; их существующий экран версий по-прежнему зависит от актуального опубликованного веб-каталога.

**Проверки:** Тесты backend, PHP-входа, версий и интерфейса DE/EN/RU задокументированы в локальном отчёте. Проверка реального аккаунта на хостинге, SmartScreen и полноценный игровой тест выполняются отдельно.
