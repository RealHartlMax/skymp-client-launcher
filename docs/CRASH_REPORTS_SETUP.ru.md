# Настройка отчётов о сбоях

Обновлено 25.10.2026. Отчёты теперь принимает отдельный раздел разработчиков
**dev.skymp-worlds.net**. Настройка трёх веб-каталогов, разрешений разработчика,
приватного хранилища, лимитов и обслуживания описана в
[DEV_PORTAL_SETUP.ru.md](DEV_PORTAL_SETUP.ru.md).

Версия лаунчера остаётся **0.2.0**, адрес API не меняется.
Для изменения маршрута веб-загрузки пересборка лаунчера не требуется.

- Перед отправкой проверьте и разрешите основной отчёт в диалоге сбоя.
- Запись дампа включается отдельно до следующего запуска игры; после
  завершения процесса его память восстановить уже нельзя.
- Существующий дамп выбирается отдельно при экспорте или отправке.
- Пока загрузка не настроена, экспортируйте локально и затем импортируйте на DEV.
- При сетевых ошибках ранее разрешённые отчёты сохраняются для повторной отправки.

Лаунчер не содержит пересобранную игровую DLL. Исправление пула потоков
требует отдельной сборки нативного клиента и нового runtime-пакета.
Технические сведения: [CRASH_REPORTS.md](CRASH_REPORTS.md).
